# A counterexample with a countable base (Fable 5.2, Nov 15, 2026)

We'll be filling this gradually.

The construction is simple (but not too pretty): take the set of all compact subsets of rationals, order that set with reverse inclusion, add a bottom element to that.

Claims:

The resulting complete lattice 

  * is not isomorphic to the set of fixed points of any Scott continuous transformation of any powerset;
  * has countable base of the induced Scott topology
  * is not quasi-Polish
