# Talking to 2026 models

After GPT-4 release, I created a repository to document the more interesting parts of my conversations with that model: https://github.com/anhinga/with-GPT-4

Eventually, that repository included some conversations with various successors of GPT-4, such as Llama-3.1-405B, Claude-3.5-Sonnet, o1-mini, o1-preview, and finally GPT-5.

Nothing has been committed to that repository since August 2025; it's time to create a fresh space to reflect work with new super-powerful generations of models.

My final conversation there was with GPT-5 about my favorite "guinea pig" open math problem, and GPT-5 was rather helpless with respect to that: https://github.com/anhinga/with-GPT-4/tree/main/GPT-5-Thinking-first-convo

But on Sunday, September 6, 2006, GPT-6-Astra has produced what seems to be a solution (a refutation of the conjecture that all complete lattices can be represented as sets of fixed points of Scott continuous transformations of powersets). It's time to start documenting all these: the road to the solution, the upcoming checks and verifications that all details are correct, and so on. That's why I am creating this repository at this moment.
