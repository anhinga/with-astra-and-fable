## talking to 2026 models

After GPT-4 release, I created a repository to document the more interesting parts of my conversations with that model: https://github.com/anhinga/with-GPT-4

Eventually, that repository included some conversations with various successors of GPT-4, such as Llama-3.1-405B, Claude-3.5-Sonnet, o1-mini, o1-preview, and finally GPT-5.

Nothing has been committed to that repository since August 2025; it's time to create a fresh space to reflect work with new super-powerful generations of models.
